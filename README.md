# 🌷 Your Little Memories — TD2026

Một cuốn sổ lưu niệm số nhỏ dành tặng cô nhân ngày Nhà giáo Việt Nam 20/11.

- `index.html`, `css/`, `js/` — trang web (HTML/CSS/JS thuần, không cần build)
- `image/` — ảnh trong album, `audio/` — playlist nhạc
- `js/data.js` — câu nói, lời chúc, lá thư, danh sách bài hát (chỉnh nội dung ở đây)
- `js/photos.js` — danh sách ảnh

Chạy thử: `python -m http.server` rồi mở http://localhost:8000
